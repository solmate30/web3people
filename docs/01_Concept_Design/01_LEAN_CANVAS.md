# Lean Canvas — web3people
> Created: 2026-03-29 00:00
> Last Updated: 2026-03-29 00:00

## 1. Problem

현재 web3/블록체인 미디어는 뉴스, 시세, 기술 분석 중심으로 운영된다. 생태계를 실제로 만들어가는 **사람**에 집중한 인터뷰 미디어는 국내외를 통틀어 부재하다.

- 독자는 "누가 이 프로젝트를 만드는가", "어떤 사람이 web3에서 일하는가"를 알고 싶지만 이를 충족하는 전문 매체가 없다
- 업계 진입을 고민하는 사람들이 롤모델을 찾기 어렵다
- web3 종사자들은 자신의 스토리를 전달할 플랫폼이 없다

## 2. Solution

web3 빌더, 창업자, 투자자, 아티스트 등 **인물**을 중심으로 한 인터뷰 웹진.

- 인물 프로필: 커리어 배경, 현재 하는 일, 비전
- 심층 인터뷰: Q&A 포맷, 롱폼 텍스트 + 이미지
- 편집자 2명이 어드민 패널에서 직접 발행

## 3. Unique Value Proposition

> "web3를 만드는 사람들의 이야기 — 뉴스가 아닌 인물"

- 기존 web3 미디어와 달리 **인물 중심 내러티브**에 집중
- 글로벌 인물을 한국어로 소개하는 브릿지 역할
- 프리미엄 에디토리얼 감성 (크립토 뉴스가 아닌 매거진 포지셔닝)

## 4. Customer Segments

- **Primary**: web3에 관심 있는 모든 사람 (입문자, 투자자, 개발자, 크리에이터)
- **Secondary**: 인터뷰 대상자 본인 및 그들의 커뮤니티 (콘텐츠 확산 주체)

## 5. Channels

- 자체 웹사이트 (web3people.co 또는 유사 도메인)
- 소셜 미디어 (Twitter/X, LinkedIn, Instagram)
- 뉴스레터 (추후)

## 6. Revenue Streams (미정)

| 모델 | 가능성 | 비고 |
|:---|:---:|:---|
| 디스플레이 광고 | 높음 | 트래픽 기반, 초기 주력 |
| 스폰서 인터뷰 | 중간 | 프로젝트/기업이 비용 지불 |
| 뉴스레터 스폰서십 | 중간 | 구독자 확보 후 |
| 유료 구독 | 낮음 (초기) | 추후 검토 |

## 7. Cost Structure

- 개발/운영 (Vercel, DB 호스팅): 월 소액
- 편집자 인건비
- 콘텐츠 제작 (사진, 번역 등)

## 8. Key Metrics

- 월간 방문자 수 (MAU)
- 인터뷰 발행 수 / 월
- 평균 체류 시간 (인터뷰 완독률)
- 소셜 공유 수

## 9. Unfair Advantage

- 인물 중심 web3 미디어 선점 효과
- 편집자의 업계 네트워크 (인터뷰이 섭외 채널)
- 한국어권 web3 미디어 중 프리미엄 에디토리얼 포지션
